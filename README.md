# Collabloom

Gen Z micro-creators struggle to monetize their content, while small businesses face high marketing costs. Collabloom bridges this gap by connecting businesses with creators who can pitch, produce content, and get paid. Our pitch showcases our platform's development and its potential to make paid collaborations accessible.

## Development

Requires Node.js and npm.

```sh
git clone https://github.com/SwetakshiNanda18/Collabloom.git
cd Collabloom
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
